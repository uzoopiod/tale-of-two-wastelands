## 📖 About

🔹 **Tale of Two Wastelands** is a powerful tool built to help you play Fallout 3 and Fallout: New Vegas as one unified game experience with Tale of Two Wastelands. Travel between the Capital Wasteland and Mojave Desert seamlessly, completing both games' content in a single playthrough.

🔸 Whether you're a seasoned professional or just getting started, **Tale of Two Wastelands** delivers a clean, intuitive experience packed with everything you need — right out of the box. Join thousands of users who've already streamlined their Fallout modding workflow. Download now and get started in minutes. 🚀

## 🚀 Features

| Feature | Description |
|---------|-------------|
| Unified World | Both Fallout 3 and New Vegas content accessible in a single playthrough |
| World Travel | Travel between Capital Wasteland and the Mojave via the game world |
| Merged Content | All quests, NPCs, and items from both games available simultaneously |
| NVSE Required | Requires New Vegas Script Extender and both game installations |
